# STUDIO NEMO — 2026

**A cinematic digital experience built around visual storytelling, motion, and modern creative production.**

Studio NEMO is a concept website for a contemporary visual production studio. Inspired by modern creative agencies and film studios, the project explores how typography, motion, imagery, and pacing can work together to create an immersive web experience.

Rather than functioning as a traditional portfolio, Studio NEMO was designed to feel like a digital extension of a creative brand—placing equal emphasis on atmosphere, storytelling, and performance.

## ⚡ Tech Stack

* **Framework:** React + Vite
* **Styling:** Tailwind CSS
* **Motion:** Framer Motion
* **Deployment:** Vercel
* **Design:** Figma

## 🛠️ Key Features

* **Cinematic Hero Experience:** Full-screen video-driven introduction designed to establish tone and visual identity.
* **Interactive Work Showcase:** Motion-enhanced project gallery featuring hover interactions and immersive transitions.
* **Behind The Scenes Gallery:** Draggable image carousel offering a glimpse into the creative process.
* **Animated Brand Carousel:** Infinite marquee showcasing featured collaborators and partners.
* **Editorial Typography System:** Large-format layouts and minimalist visual hierarchy inspired by modern studio websites.
* **Performance Focused:** Optimized media delivery and responsive design with a perfect Lighthouse score.

## 🚀 Getting Started

1. Clone the repository:
   `git clone [your-repository-link]`

2. Install dependencies:
   `npm install`

3. Start the development server:
   `npm run dev`

4. Build for production:
   `npm run build`
